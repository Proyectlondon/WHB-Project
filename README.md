# WHB Project · Campo de Aliento V1.5

Versión nueva de la experiencia web de WHB Project. Esta carpeta no reutiliza el HTML, CSS ni JavaScript del prototipo anterior; solo comparte el catálogo y los activos aprobados.

## Dirección

- El viento vive en un Canvas fijo de página completa.
- Hojas y semillas tienen tres profundidades, baja opacidad y una zona central protegida para que el contenido siempre sea legible.
- El cursor de escritorio usa una flecha vectorial crema y dorada, estable y legible; el clic conserva un pequeño soplido ambiental sobre las hojas.
- La apertura usa un video cinematográfico de 8 segundos como puerta de entrada y aparece en cada recarga; `?no-intro=1` permite revisar directamente el contenido.
- `prefers-reduced-motion` conserva la narrativa y reduce la animación.

## Contenido

- 46 audios locales, únicamente archivos identificados como `Radio Version`.
- 22 videos oficiales embebidos desde YouTube.
- 14 imágenes curadas del archivo entregado.
- Capítulos separados para historia, integrantes, música, videos, arte, 3FR, servicios y contacto.
- Producciones de audio plegables con control +/−; la primera se muestra abierta y las demás se pueden abrir a demanda.
- Títulos, copys y tarjetas entran de forma progresiva al aparecer en pantalla; con reducción de movimiento se muestran sin transición.

La apertura mejorada en Magnific está guardada en `assets/video/hero-whb-2k.mp4` y funciona sin sonido. `assets/video/hero-whb-final.mp4`, `assets/video/hero-whb-smile.mp4` y `assets/video/hero-whb.mp4` quedan como respaldos. No se publica ni se conecta a cuentas externas desde esta fase.
